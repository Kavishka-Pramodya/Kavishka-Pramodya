## A little about me

I'm **Pramodya Rathnayaka**, an Information Systems student at the **University of Colombo School of Computing (UCSC)** in Sri Lanka.

I enjoy turning ideas into practical applications and exploring what happens when software interacts with the physical world.

My interests move between web development, database-driven systems, mobile applications, embedded programming, and robotics.

I believe the best way to learn technology is to build something, test it, discover what breaks, and improve it.
